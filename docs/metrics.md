# List of Metrics

The Maia API service exposes all metrics generated by the standard Go client for Prometheus (e.g. `go_memstats_alloc_bytes` for memory usage or `go_goroutines` for goroutine count), plus the following Maia-specific metrics.

## API Service

| Type | Metric | Labels | Description |
| --- | --- | --- | --- |
| Counter | `maia_logon_errors_count` | — | Number of logon errors (technical failures) |
| Counter | `maia_logon_failures_count` | — | Number of logon failures (wrong credentials) |
| Histogram | `maia_request_duration_seconds` | `handler` | Request latency per handler |
| Gauge | `maia_requests_inflight` | — | Number of concurrent requests |
| Histogram | `maia_response_size_bytes` | `handler` | Response size per handler |
| Counter | `maia_requests_total` | `handler`, `code`, `method` | Total requests per handler, response code and HTTP method |
| Counter | `maia_tsdb_errors_count` | — | Errors from the underlying Prometheus TSDB |
| Counter | `maia_keystone_cache_hits_total` | `cache` | Keystone cache lookups served from cache |
| Counter | `maia_keystone_cache_misses_total` | `cache` | Keystone cache lookups requiring a live Keystone call |

**Note:** Histogram metrics expose `_count`, `_sum` and `_bucket` sub-metrics (e.g. `maia_request_duration_seconds_bucket`). Compute quantiles with `histogram_quantile(0.99, rate(maia_request_duration_seconds_bucket[5m]))`.

**Note:** `maia_keystone_cache_*` `cache` label values: `token`, `project_tree`, `user_projects`, `user_id`, `project_scope`.
